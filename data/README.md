# Dataset instructions

Download the original Microsoft Azure Predictive Maintenance dataset from:
https://www.kaggle.com/datasets/arnabbiswas1/microsoft-azure-predictive-maintenance/data

Expected files (verify actual files): PdM_telemetry.csv, PdM_errors.csv, PdM_maint.csv, PdM_failures.csv, PdM_machines.csv.

Store local downloads in `data/raw/`, extracts in `data/interim/`, and generated modeling datasets in `data/processed/`. These files are gitignored. Share large data through an agreed team storage location; record file versions and SHA256 checksums in the audit report. Never commit personal credentials.
